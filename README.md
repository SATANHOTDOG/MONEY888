​🛠️ 啟動指南：如何綁定你的 Google 試算表
​這套系統是一隻飢餓的猛獸，它需要吃你的「Google 試算表 CSV」才能運作。請按照以下步驟餵食：
​步驟一：淨化你的試算表
​請確保你的試算表是一個「純粹的資料庫」。不要在資料最下方加總任何金額！ 把底下那些算獎金的廢物欄位全砍了，這些交給系統算就好，不要讓多餘的排版干擾程式讀取。
​步驟二：把試算表發佈到網路 (CSV)
​打開你的 Google 試算表。
​點擊左上角單單：檔案 > 共用 > 發佈到網路。
​第一個下拉選單選擇你的「出貨表」分頁。
​第二個下拉選單選擇 「逗號分隔值 (.csv)」。
​點擊「發佈」，然後複製彈出來的那一長串網址。
