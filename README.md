HOLA 家具專員業績續命系統 (極簡暴力 2% 版)
​寫給在總公司數學黑箱與奧客殺價之間，夾縫求生的第一線家具業務。

​這不是一個充滿夢想與願景的財務報表，這是一台無情的資本結算機。當總公司的 POS 系統總是用一堆凡人無法理解的「特殊專案剔除」跟「平均折扣率」來吃掉你小數點後的獎金時，你需要一個只講武德、不講感情的底層邏輯來幫你算錢。

​這套系統已經全面放棄治療，移除了所有花裡胡哨的折扣試算與原價比對。我們只看一個東西：除稅後的錢。

​核心功能 (生存配備)

​■無腦 2% 暴力結算：不要再管什麼 2.5%、3% 的浮動級距了。只要你這個月賣沙發跟床墊的除稅總額，能艱難地爬過 40 萬生死線，系統就會直接、粗暴地把總額乘上 2%。算出來的數字可能比官方少一點，但至少你月底核對薪資單的時候不會因為期待落空而氣到中風。

​■一條龍無限延伸帳本：放棄你那分類強迫症的 Excel 分頁吧。1 月到 12 月的出貨明細，請全部在同一個分頁無腦往下貼。中間你想插幾百行空白當作換月區隔隨便你，系統內建垃圾過濾器，會自動無視那些沒有有效日期的廢話欄位。

​■7 天奪命催魂警報：卡在「未排程」狀態，且距離「貨押日」不到 7 天的定時炸彈，系統會在畫面上直接亮起死亡紅燈閃爍。防止你忘記出貨被客訴到飛天，保住你微薄的底薪。

​■直球對決的訂單彈窗：點擊任何一筆訂單，沒有多餘的干擾欄位，只有客資、備註、以及最重要的「除稅後業績」。這就是你打電話去跟客人喬交期的戰術面板
